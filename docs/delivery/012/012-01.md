## Requirements

A new layout file `hugo/layouts/about-doulas/single.html` is created.
The markdown file `hugo/content/about-doulas.md` specifies `type: "about-doulas"` in its front matter.
The layout file contains the HTML structure for the page, calling partials for each section.

## Implementation Plan

-Update `hugo/content/about-doulas.md` to set `type: "about-doulas"` in the front matter.
-Create a new layout file at `hugo/layouts/about-doulas/single.html`.
-This layout will define the main block and call partials for each section.
Create a new directory for partials: `hugo/layouts/partials/about-doulas/`.
Create a separate partial file for each section inside the new directory (e.g., `birth.html`, `postpartum.html`, `faq.html`).
-Call these partials from the `layouts/about-doulas/single.html` layout to build the page.

- The FAQ section will be a list of questions for now, with interactive elements to be added in a later task.

## Verification

All sections are rendered correctly from the partials via the new layout.
