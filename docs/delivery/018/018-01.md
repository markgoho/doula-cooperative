# 018-01 Get Pagefind working with minimal setup (POC)

[Back to task list](./tasks.md)

## Description

This task creates a minimal working proof-of-concept for Pagefind search functionality. The goal is to get search working quickly so we can learn how Pagefind behaves and what it can do. We'll use the simplest possible setup to get search results appearing on the Find a Doula page.

## Requirements

1. **Minimal Pagefind Setup**
   - Install Pagefind using bun/npx
   - Run basic indexing on the built Hugo site
   - Verify search index is generated

2. **Basic Search UI**
   - Add Pagefind's prebuilt UI to the Find a Doula page
   - Use default Pagefind styling (no custom CSS yet)
   - Ensure search input appears and accepts text

3. **Working Search Results**
   - Verify search returns results when typing
   - Confirm clicking results navigates to pages
   - Test that search works across site content

4. **Learning Focus**
   - Document what we learn about Pagefind behavior
   - Note any unexpected behavior or limitations
   - Identify what configuration options are available

## Implementation Plan

1. **Install and Test Pagefind**

   ```bash
   # Install Pagefind
   bunx pagefind --version

   # Build Hugo site
   hugo

   # Generate search index
   bunx pagefind --site public
   ```

2. **Add Basic Search UI to Find a Doula Page**
   - Update `hugo/layouts/partials/find-a-doula/search.html`
   - Add Pagefind CSS and JS files
   - Use the simplest possible Pagefind UI configuration

3. **Test Basic Functionality**
   - Verify search index is created in `public/_pagefind/`
   - Test search on Find a Doula page
   - Confirm results appear and are clickable

4. **Document Learnings**
   - Note what content gets indexed by default
   - Document Pagefind UI configuration options
   - Identify what needs customization for our site
