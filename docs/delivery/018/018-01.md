# 018-01 Set up Pagefind in the build process

[Back to task list](./tasks.md)

## Description

This task involves installing Pagefind and integrating it into the Hugo build pipeline. Pagefind will run after Hugo generates the static site to create a searchable index of all content. The integration should work seamlessly with the existing build process and be compatible with deployment pipelines.

## Requirements

1. **Pagefind Installation**
   - Install Pagefind using bun/npx (not npm directly)
   - Ensure the installation works in both local development and CI/CD environments
   - Use a specific version to ensure consistency across environments

2. **Build Integration**
   - Pagefind must run after Hugo builds the site
   - The command should target the `public` directory where Hugo outputs files
   - Build process should fail gracefully if Pagefind encounters errors

3. **Script Configuration**
   - Add appropriate scripts to package.json for ease of use
   - Ensure the build process is documented and repeatable

4. **Firebase Deployment Compatibility**
   - Verify that the Pagefind output works with Firebase hosting
   - Ensure \_pagefind directory is included in deployment

## Implementation Plan

1. **Add Pagefind to package.json**

   ```json
   {
     "scripts": {
       "build": "hugo && bun run index",
       "index": "bunx pagefind --site public",
       "dev": "hugo server",
       "build:search": "hugo && bunx pagefind --site public --serve"
     }
   }
   ```

2. **Create or update build script**
   - Ensure Hugo runs first to generate the site
   - Run Pagefind after Hugo completes successfully
   - Handle errors appropriately

3. **Update .gitignore**
   - Add `public/_pagefind/` to .gitignore as it's generated content

4. **Test the integration**
   - Run the build locally
   - Verify \_pagefind directory is created in public/
   - Check that search assets are generated

## Verification
