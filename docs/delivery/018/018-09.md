1. **Create main search documentation file**

   ````markdown
   # Search Implementation Documentation

   ## Overview

   The Doula Cooperative website uses Pagefind for static search functionality.
   Pagefind is a fully static search library that runs after the Hugo build
   process to create a client-side search index.

   ## Architecture

   ### Build Process

   1. Hugo generates static HTML files to `public/`
   2. Pagefind indexes the HTML files
   3. Search index is output to `public/_pagefind/`
   4. Client loads search assets on demand

   ### Components

   - **Pagefind CLI**: Indexes content during build
   - **Pagefind UI**: Prebuilt search interface
   - **Progressive Enhancement**: Fallback to DuckDuckGo
   - **Lazy Loading**: Assets load on user interaction

   ## Configuration

   ### Pagefind Settings

   - Root selector: `main` (indexes only main content)
   - Excluded selectors: `nav, header, footer, .no-index`
   - Language: English (`en`)
   - Output: `public/_pagefind/`

   ### Build Commands

   ```bash
   # Build site and index
   hugo && bunx pagefind --site public

   # Development with search
   hugo && bunx pagefind --site public --serve
   ```
   ````

   ## File Structure

   ```
   public/
   └── _pagefind/
       ├── pagefind.js          # Core search library
       ├── pagefind-ui.js       # UI component
       ├── pagefind-ui.css      # UI styles
       ├── pagefind.en_*.pf     # Search index chunks
       └── pagefind-fragment-*  # Content fragments
   ```

2. **Create troubleshooting guide**

   ````markdown
   # Search Troubleshooting Guide

   ## Common Issues

   ### Search not appearing

   1. Check if `_pagefind` directory exists in `public/`
   2. Verify Pagefind ran during build
   3. Check browser console for errors
   4. Ensure JavaScript is enabled

   ### No search results

   1. Verify content is within `<main>` tags
   2. Check for `data-pagefind-ignore` attributes
   3. Ensure content is in HTML (not JavaScript rendered)
   4. Rebuild search index

   ### Performance issues

   1. Check index size (should be < 1MB compressed)
   2. Verify lazy loading is working
   3. Monitor network requests
   4. Check for duplicate indexing

   ## Debugging

   ### Enable debug mode

   ```javascript
   new PagefindUI({
     element: "#search",
     showSubResults: true,
     debugging: true,
   });
   ```
   ````

   ### Check index statistics

   ```bash
   bunx pagefind --site public --verbose
   ```

   ````markdown
   # Search API Customization

   ## Using Pagefind API directly

   Instead of the prebuilt UI, you can use the API:

   ```javascript
   import * as pagefind from "/pagefind/pagefind.js";

   await pagefind.init();

   const search = await pagefind.search("doula");
   const results = await Promise.all(search.results.map(r => r.data()));
   ```
   ````

   ## Custom result rendering

   ```javascript
   function renderResults(results) {
     return results
       .map(
         result => `
       <article class="search-result">
         <h3>
           <a href="${result.url}">
             ${result.meta.title}
           </a>
         </h3>
         <p>${result.excerpt}</p>
       </article>
     `,
       )
       .join("");
   }
   ```

   ## Advanced filtering

   ```javascript
   // Add filters to content
   <div data-pagefind-filter="type:doula">...</div>;

   // Filter in search
   const search = await pagefind.search("birth", {
     filters: { type: "doula" },
   });
   ```
