# 018-05 Add progressive enhancement and fallback behavior

[Back to task list](./tasks.md)

## Description

This task implements progressive enhancement for the search functionality, ensuring that users without JavaScript or those experiencing loading failures still have a functional search experience. We'll implement a fallback to an external search engine (DuckDuckGo) while maintaining the enhanced Pagefind experience for users with JavaScript enabled.

## Requirements

1. **Fallback Search Form**
   - Implement a standard HTML form that works without JavaScript
   - Form should submit to DuckDuckGo with site-specific search
   - Include hidden field to limit search to doulacooperative.com
   - Maintain visual consistency with enhanced version

2. **Progressive Enhancement**
   - Start with functional HTML form
   - Enhance with Pagefind when JavaScript is available
   - Handle Pagefind loading failures gracefully
   - Provide smooth transition between states

3. **Error Handling**
   - Detect when Pagefind assets fail to load
   - Fall back to basic form if initialization fails
   - Log errors appropriately for debugging
   - Inform users if enhanced search is unavailable

4. **Accessibility**
   - Ensure both versions are fully accessible
   - Maintain keyboard navigation in both states
   - Provide appropriate ARIA labels and announcements

## Implementation Plan

1. **Create base HTML form structure**

   ```html
   <section class="text-content search-section">
     <p>
       Search across all Doula profiles, bios, specializations, and locations
     </p>

     <!-- Fallback form (enhanced by JS when available) -->
     <form
       id="search-form"
       class="search-form"
       role="search"
       action="https://duckduckgo.com/"
       method="GET"
     >
       <div class="search-input-group">
         <label for="search-input" class="visually-hidden">
           Search for doulas, services, or information
         </label>
         <input
           id="search-input"
           type="search"
           name="q"
           placeholder="Search for what's important"
           required
         />
         <input type="hidden" name="sites" value="doulacooperative.com" />
         <button type="submit" class="button">Search</button>
       </div>
     </form>

     <!-- Container for enhanced search (hidden initially) -->
     <div id="pagefind-search" class="pagefind-search" style="display: none;">
       <div id="search"></div>
     </div>
   </section>
   ```

2. **Implement progressive enhancement JavaScript**

   ```javascript
   // Progressive enhancement for search
   (function () {
     const fallbackForm = document.getElementById("search-form");
     const enhancedSearch = document.getElementById("pagefind-search");

     // Function to initialize Pagefind
     function initializePagefind() {
       try {
         // Load Pagefind CSS
         const pagefindCSS = document.createElement("link");
         pagefindCSS.rel = "stylesheet";
         pagefindCSS.href = "/pagefind/pagefind-ui.css";
         document.head.appendChild(pagefindCSS);

         // Load Pagefind JS
         const pagefindJS = document.createElement("script");
         pagefindJS.src = "/pagefind/pagefind-ui.js";
         pagefindJS.onload = function () {
           // Initialize Pagefind UI
           new PagefindUI({
             element: "#search",
             showSubResults: true,
             showImages: false,
             resetStyles: false,
           });

           // Hide fallback form, show enhanced search
           fallbackForm.style.display = "none";
           enhancedSearch.style.display = "block";
         };

         pagefindJS.onerror = function () {
           console.error("Failed to load Pagefind");
           // Keep fallback form visible
         };

         document.body.appendChild(pagefindJS);
       } catch (error) {
         console.error("Error initializing Pagefind:", error);
         // Keep fallback form visible
       }
     }

     // Initialize on DOMContentLoaded
     if (document.readyState === "loading") {
       document.addEventListener("DOMContentLoaded", initializePagefind);
     } else {
       initializePagefind();
     }
   })();
   ```

3. **Style both versions consistently**
