# 018-03 Implement basic search UI on Find a Doula page

[Back to task list](./tasks.md)

## Description

This task involves replacing the placeholder search form on the Find a Doula page with Pagefind's functional search UI. We'll integrate Pagefind's prebuilt UI component, which provides search input, results display, and basic interactivity out of the box. The implementation should maintain the existing page structure while adding search functionality.

## Requirements

1. **Search UI Integration**
   - Replace the static search form in search.html partial
   - Integrate Pagefind's CSS and JavaScript files
   - Initialize Pagefind UI with appropriate configuration
   - Maintain the existing visual layout structure

2. **Functionality Requirements**
   - Search input should be functional and responsive
   - Results should display below the search input
   - Search should work across all indexed content
   - Results should show page titles and excerpts

3. **Page Integration**
   - Search should work within the Find a Doula page context
   - Should not break existing page functionality
   - Maintain responsive design

4. **Asset Loading**
   - Properly load Pagefind CSS and JS files
   - Ensure assets are available after build process
   - Handle potential loading errors gracefully

## Implementation Plan

1. **Update search.html partial**

   ```html
   <section class="text-content search-section">
     <p>
       Search across all Doula profiles, bios, specializations, and locations
     </p>

     <!-- Pagefind UI styles -->
     <link href="/pagefind/pagefind-ui.css" rel="stylesheet" />

     <!-- Search container -->
     <div id="search"></div>

     <!-- Pagefind UI script -->
     <script src="/pagefind/pagefind-ui.js"></script>
     <script>
       window.addEventListener("DOMContentLoaded", event => {
         new PagefindUI({
           element: "#search",
           showSubResults: true,
           showImages: false,
           resetStyles: false,
         });
       });
     </script>
   </section>
   ```

2. **Configure Pagefind UI options**
   - Set appropriate result count
   - Configure excerpt length
   - Set up proper placeholder text
   - Configure result click behavior

3. **Handle edge cases**
   - Add error handling for missing assets
   - Provide feedback for no results
   - Handle loading states
