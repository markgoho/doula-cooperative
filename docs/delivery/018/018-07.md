# 018-07 Ensure search accessibility compliance

[Back to task list](./tasks.md)

## Description

This task ensures that the search functionality meets WCAG 2.1 AA accessibility standards. We need to implement proper ARIA labels, keyboard navigation, screen reader support, and ensure all interactive elements are accessible to users with disabilities. Both the fallback form and enhanced Pagefind interface must be fully accessible.

## Requirements

1. **ARIA Implementation**
   - Add appropriate ARIA labels and descriptions
   - Implement live regions for search results
   - Use proper ARIA roles for search components
   - Ensure ARIA attributes are correctly applied

2. **Keyboard Navigation**
   - Full keyboard accessibility for all functions
   - Logical tab order through search interface
   - Escape key to close/clear search
   - Arrow keys for result navigation

3. **Screen Reader Support**
   - Announce search results count
   - Read result content clearly
   - Provide context for interactions
   - Handle loading and error states

4. **Visual Accessibility**
   - Maintain color contrast ratios (4.5:1 minimum)
   - Clear focus indicators for all interactive elements
   - Sufficient text size and spacing
   - No reliance on color alone for information

## Implementation Plan

1. **Enhance fallback form accessibility**

   ```html
   <form
     id="search-form"
     class="search-form"
     role="search"
     aria-label="Search the Doula Cooperative website"
   >
     <div class="search-input-group">
       <label for="search-input">
         Search for doulas, services, or information
       </label>
       <input
         id="search-input"
         type="search"
         name="q"
         placeholder="Search for what's important"

       />
       <span id="search-help" class="visually-hidden">
         Search across all doula profiles, specializations, and services
       </span>
       <input type="hidden" name="sites" value="doulacooperative.com" />
       <button type="submit" class="button" aria-label="Submit search">
         <span aria-hidden="true">Search</span>
         <span class="visually-hidden">Submit search query</span>
       </button>
     </div>
   </form>
   ```

2. **Add ARIA live regions for results**

   ```javascript
   // Create live region for announcements
   const liveRegion = document.createElement("div");
   liveRegion.setAttribute("role", "status");
   liveRegion.setAttribute("aria-live", "polite");
   liveRegion.setAttribute("aria-atomic", "true");
   liveRegion.className = "visually-hidden";
   document.body.appendChild(liveRegion);

   // Announce results
   function announceResults(count, query) {
     if (count === 0) {
       liveRegion.textContent = `No results found for "${query}"`;
     } else if (count === 1) {
       liveRegion.textContent = `1 result found for "${query}"`;
     } else {
       liveRegion.textContent = `${count} results found for "${query}"`;
     }
   }
   ```

3. **Implement keyboard navigation**

   ```javascript
   // Enhanced keyboard navigation for Pagefind
   document.addEventListener("keydown", e => {
     const results = document.querySelectorAll(".pagefind-ui__result");
     const activeElement = document.activeElement;

     // Handle arrow key navigation
     if (results.length > 0) {
       const currentIndex = Array.from(results).indexOf(activeElement);

       switch (e.key) {
         case "ArrowDown":
           e.preventDefault();
           if (currentIndex < results.length - 1) {
             results[currentIndex + 1].focus();
           }
           break;

         case "ArrowUp":
           e.preventDefault();
           if (currentIndex > 0) {
             results[currentIndex - 1].focus();
           }
           break;

         case "Escape":
           // Clear search and return focus to input
           const searchInput = document.querySelector(
             ".pagefind-ui__search-input",
           );
           if (searchInput) {
             searchInput.value = "";
             searchInput.focus();
           }
           break;
       }
     }
   });
   ```

4. **Enhance focus styles**

   ```scss
   // Clear focus indicators
   *:focus {
     outline: 3px solid #8b5cf6;
     outline-offset: 2px;
   }

   // Skip link for keyboard users
   .skip-to-search {
     position: absolute;
     left: -9999px;

     &:focus {
       position: fixed;
       top: 1rem;
       left: 1rem;
       z-index: 9999;
       padding: 1rem;
       background: white;
       box-shadow: 0 2px 8px rgba(0, 0, 0, 0.2);
     }
   }

   // High contrast mode support
   @media (prefers-contrast: high) {
     .pagefind-ui__result {
       border: 2px solid;
     }

     mark {
       text-decoration: underline;
       background: transparent;
     }
   }
   ```

5. **Add loading and error state announcements**

   ```javascript
   // Announce loading state
   function announceLoading() {
     liveRegion.textContent = "Loading search results...";
   }

   // Announce errors
   function announceError(error) {
     liveRegion.textContent = `Search error: ${error}. Please try again.`;
   }
   ```
