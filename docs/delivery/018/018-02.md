# 018-02 Configure Pagefind indexing scope and parameters

[Back to task list](./tasks.md)

## Description

This task involves configuring Pagefind to properly index the Doula Cooperative website content. We need to define what content should be indexed, exclude non-content elements, and optimize the indexing parameters for the best search experience. This includes setting up appropriate selectors, filters, and language settings.

## Requirements

1. **Content Scope Definition**
   - Index all doula profile pages with names, bios, specializations, locations
   - Index service pages (About Doulas, Join Cooperative)
   - Index informational pages (About the Cooperative, Contact)
   - Exclude navigation, headers, footers from indexing

2. **Pagefind Configuration**
   - Use appropriate CSS selectors to target content areas
   - Configure language settings for proper text processing
   - Set up appropriate chunk sizes for optimal performance
   - Configure meta tag extraction for better search results

3. **Performance Optimization**
   - Balance index size vs search quality
   - Configure appropriate word stemming
   - Set up stop words if needed

4. **Search Result Quality**
   - Ensure page titles are properly indexed
   - Configure excerpt generation for search results
   - Set up proper weighting for different content types

## Implementation Plan

1. **Create Pagefind configuration file**

   ```json
   {
     "site": "public",
     "root_selector": "main",
     "exclude_selectors": [
       "nav",
       "header",
       "footer",
       ".no-index",
       "[data-pagefind-ignore]"
     ],
     "force_language": "en",
     "keep_index_url": true
   }
   ```

2. **Add data attributes to HTML templates**
   - Add `data-pagefind-body` to main content areas
   - Add `data-pagefind-ignore` to elements that shouldn't be indexed
   - Add `data-pagefind-meta` attributes for better metadata

3. **Configure indexing parameters**

   ```bash
   bunx pagefind --site public \
     --root-selector "main" \
     --exclude-selectors "nav,header,footer,.no-index" \
     --force-language en
   ```

4. **Set up content weighting**
   - Use `data-pagefind-weight` for important content
   - Prioritize doula names and specializations
