# 018-04 Style search interface to match site design

[Back to task list](./tasks.md)

## Description

This task involves customizing the appearance of Pagefind's search UI to match the Doula Cooperative's visual design system. We need to override Pagefind's default styles to align with the site's colors, typography, spacing, and overall aesthetic while maintaining functionality and accessibility.

## Requirements

1. **Visual Consistency**
   - Match site's color scheme (purples, warm tones)
   - Use consistent typography (fonts, sizes, weights)
   - Align spacing and padding with site standards
   - Maintain the professional, welcoming aesthetic

2. **Component Styling**
   - Style search input to match other form inputs
   - Customize result cards appearance
   - Style highlighted search terms
   - Design loading and empty states

3. **Responsive Design**
   - Ensure styles work on all screen sizes
   - Maintain touch-friendly targets on mobile
   - Adjust result layout for different viewports

4. **Accessibility Preservation**
   - Maintain color contrast ratios
   - Keep focus indicators visible
   - Ensure readable text sizes

## Implementation Plan

1. **Create search-specific SCSS file**

   ```scss
   // hugo/assets/scss/search.scss

   // Override Pagefind UI variables
   .pagefind-ui {
     --pagefind-ui-scale: 1;
     --pagefind-ui-primary: #8b5cf6; // Site purple
     --pagefind-ui-text: #374151;
     --pagefind-ui-background: #ffffff;
     --pagefind-ui-border: #e5e7eb;
     --pagefind-ui-tag: #f3e8ff;
     --pagefind-ui-border-radius: 0.5rem;
     --pagefind-ui-font: inherit;
   }

   // Custom search input styles
   .pagefind-ui__search-input {
     padding: 1rem;
     font-size: 1.125rem;
     border: 2px solid var(--pagefind-ui-border);

     &:focus {
       border-color: var(--pagefind-ui-primary);
       outline: 3px solid rgba(139, 92, 246, 0.1);
     }
   }

   // Result card styling
   .pagefind-ui__result {
     padding: 1.5rem;
     margin-bottom: 1rem;
     background: #fafafa;
     border-radius: var(--pagefind-ui-border-radius);
     transition: all 0.2s ease;

     &:hover {
       background: #f3e8ff;
       transform: translateY(-2px);
       box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
     }
   }

   // Result title styling
   .pagefind-ui__result-title {
     color: var(--pagefind-ui-primary);
     font-weight: 600;
     text-decoration: none;

     &:hover {
       text-decoration: underline;
     }
   }

   // Highlighted search terms
   .pagefind-ui__result-excerpt mark {
     background-color: #fef3c7;
     color: inherit;
     font-weight: 600;
   }
   ```

2. **Import styles in appropriate location**
   - Add to main SCSS or create page-specific inclusion
   - Ensure proper cascade order

3. **Add custom button styling**

   ```scss
   .pagefind-ui__search-clear {
     // Style to match site buttons
   }

   .pagefind-ui__button {
     // Pagination button styles
   }
   ```

4. **Mobile-specific adjustments**

   ```scss
   @media (max-width: 768px) {
     .pagefind-ui__results {
       padding: 1rem;
     }

     .pagefind-ui__result {
       padding: 1rem;
     }
   }
   ```
