# 016-04 Implement Generic Fallback Card

[Back to task list](./tasks.md)

## Description

This task involves creating a generic social card image that will be used as a fallback for all pages on the site that are not doula profiles. This ensures that even when sharing general pages like "About Us" or "Contact," a branded and visually acceptable card is displayed.

## Requirements

- Create a single, static fallback image.
- The image should be `1200x630` pixels.
- It should contain the Doula Cooperative logo and perhaps a generic title like "The Doula Cooperative".
- The image must be saved in a central location, such as `hugo/assets/images/social-fallback.png`.
- The Hugo templates must be configured to use this image when a page-specific social card is not available.

## Implementation Plan

1.  Design a simple fallback image using a graphic design tool (or generate it with code if preferred).
2.  The design should be simple, clean, and align with the site's branding.
3.  Save the final image as `social-fallback.png` in the `hugo/assets/images/` directory.
4.  Ensure the logic in the meta tag template (from `016-03`) correctly points to this image's URL for all non-doula pages.

## Verification

- The file `hugo/assets/images/social-fallback.png` exists and is the correct image.
- When viewing the source of any non-doula page, the `og:image` and `twitter:image` meta tags point to the absolute URL of this fallback image.
- The fallback image displays correctly when sharing a link to a generic page.
