# 016-01 Research and PoC for Hugo Image Generation

[Back to task list](./tasks.md)

## Description

This task focuses on researching and evaluating potential libraries or Hugo modules for dynamic image generation. The goal is to find a solution that can be integrated into the Hugo build process to create social card images at build time. The research will conclude with a proof-of-concept (PoC) to validate that the chosen tool can generate a basic image containing both text and another image (the doula's profile picture).

## Requirements

-   Identify at least 2-3 potential image generation libraries compatible with Hugo/Go.
-   Evaluate them based on ease of use, documentation, performance, and features.
-   Create a simple PoC that generates a sample image.
-   The PoC image must include custom text and an embedded picture.

## Implementation Plan

1.  Research Hugo modules and Go libraries for image manipulation (e.g., `hugo-social-cards`, `go-cairo`, `gg`).
2.  Select the most promising candidate for a PoC.
3.  Set up a test Hugo project or a separate branch to build the PoC.
4.  Write the code to generate a sample `300x200` PNG image.
5.  The image should have a solid color background, contain the text "Hello, World!", and include a small placeholder image.
6.  Document the findings and the PoC code.

## Verification
