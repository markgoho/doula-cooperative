# 016-03 Update Hugo Meta Tag Templates

[Back to task list](./tasks.md)

## Description

This task involves updating the Hugo templates to include the necessary Open Graph and Twitter Card meta tags. For doula profile pages, these tags will point to the unique social card images generated in task `016-02`. For all other pages, they will point to the generic fallback card.

## Requirements

- Update the existing `meta.html` partial or create a new one to manage social meta tags.
- The template must conditionally check if a generated `social-card.png` exists for the current page.
- If a custom card exists, the `og:image` and `twitter:image` tags must point to its absolute URL.
- If no custom card exists, the tags must point to the generic fallback image.
- Other meta tags (`og:title`, `og:description`, etc.) should be populated with appropriate page data.

## Implementation Plan

1.  Locate the primary `head` partial in the Hugo project (`layouts/partials/head/meta.html`).
2.  Add or modify the logic within this file to handle social cards.
3.  Use Hugo's `with .Resources.GetMatch "social-card.png"` or a similar function to check for the existence of the generated card.
4.  Construct the `meta` tags with the correct URLs. Use `absURL` to ensure they are absolute.
5.  Ensure that the page title and description are also correctly populated in the `og:title`, `og:description`, `twitter:title`, and `twitter:description` tags.

## Verification

- When viewing the source of a doula profile page, the `og:image` meta tag points to that doula's specific `social-card.png`.
- When viewing the source of a non-doula page (e.g., the "About Us" page), the `og:image` meta tag points to the generic fallback image URL.
- All required Open Graph and Twitter Card meta tags are present in the `<head>` of all pages.
- The URLs in the meta tags are absolute and correct.
