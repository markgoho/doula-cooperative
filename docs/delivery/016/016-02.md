[Back to task list](./tasks.md)

## Description

Using the findings from the PoC in task `016-01`, this task involves implementing the full logic to generate a unique social card for each doula profile page. The process will run during the Hugo build, creating an image for each doula that includes their profile photo, their name and credentials, and the "Doula Cooperative" brand text at the bottom.

## Requirements

-   The generation script must iterate through all doula profile pages.
-   For each doula, it must generate a social card image (e.g., `1200x630` pixels).
-   The card must include:
    -   The doula's profile picture.
    -   The doula's full name and credentials.
    -   The static text "Doula Cooperative".
-   Generated images should be saved to a sensible location within the page's resources, like `.../doula-name/social-card.png`.
-   The process should be reasonably performant and not excessively slow down the site build.

## Implementation Plan

1.  Integrate the chosen image generation library into the Hugo project structure.
2.  Create a new Hugo partial or layout responsible for triggering the image generation.
3.  Write the script/template logic to:
    -   Loop through each page in the `doulas` section.
    -   Access the page's title (name), credentials (`.Params.credentials`), and profile image.
    -   Compose these elements into a single image using the library.
    -   Save the resulting image to the page's bundle.
4.  Refine the visual layout (font, colors, positioning) to match the requirements.

## Verification

-   A unique `social-card.png` is generated for every doula in the `content/doulas` directory.
-   Each generated card correctly displays the respective doula's photo, name, and credentials.
-   The "Doula Cooperative" text is present and correctly positioned on every card.
-   The build process completes successfully without errors related to image generation.
-   The generated images are of good quality and reasonable file size.
