## Description

This final task is to perform end-to-end testing of the entire social card implementation. It involves using official platform-specific debugger tools and, if possible, manual sharing to ensure the generated cards for both doula profiles and generic pages appear correctly on Facebook, X, LinkedIn, and Instagram.

## Requirements

- Verify social card functionality across all specified platforms.
- Test at least two different doula profile pages.
- Test at least two different generic pages (e.g., "About" and "FAQ").
- Confirm that the correct image (unique or fallback) is displayed.
- Confirm that the title and description are correct.

## Implementation Plan

1.  Build the Hugo site to generate all assets, including the social card images.
2.  Use the following tools to test URLs from the local or a staging environment:
    - **Facebook:** Sharing Debugger
    - **X (Twitter):** Card Validator
    - **LinkedIn:** Post Inspector
    - **Instagram:** (Manual testing by sharing a link in a message or story may be required as they don't have a public validator tool).
3.  For each platform, test one doula profile URL and one generic page URL.
4.  Capture screenshots of the debugger previews as evidence.
5.  Document any issues or inconsistencies found.

## Verification

- A test log or report is created, showing the results for each platform.
- Screenshots confirm that the social cards for both doula profiles and generic pages render correctly on all validators.
- The title, description, and image are all accurate in the previews.
- No broken images or missing metadata are reported by the validation tools.
