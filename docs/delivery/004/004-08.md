## Overview

This document explains how to use and update the global theme/styles for the Doula Cooperative Hugo site. The theme system is based on CSS custom properties (variables) defined in modular SCSS files:

- `hugo/assets/scss/colors.scss` — color tokens
- `hugo/assets/scss/typography.scss` — typography tokens and styles
- `hugo/assets/scss/spacing.scss` — spacing scale
- `hugo/assets/scss/base.scss` — base styles and resets
- `hugo/assets/scss/styles.scss` — main entry point (imports all others)

## How to Use Theme Variables

### Colors

Use color variables for backgrounds, text, borders, and accents:

```scss
.card {
  background: var(--color-light-bg);
  color: var(--color-text-main);
  border: 1px solid var(--color-border-accent);
}
```

### Typography

Use typography variables for font family, size, weight, and line height:

```scss
h1 {
  font-family: var(--font-family-main);
  font-size: var(--font-size-xl);
  font-weight: var(--font-weight-boldest);
  line-height: var(--line-height-tight);
}
```

### Spacing

Use spacing variables for margin, padding, and gap:

```scss
.section {
  padding: var(--spacing-lg) 0;
}
.grid {
  gap: var(--spacing-md);
}
```

## How to Update Theme Tokens

1. **Open the relevant SCSS file** in `hugo/assets/scss/` (e.g., `colors.scss`, `typography.scss`, or `spacing.scss`).
2. **Add or update a variable** following the existing naming convention and using `rem` units for spacing/typography.
   - Example: `--color-accent-bg: #1b5665;`
   - Example: `--spacing-xl: 3rem;`
3. **Use the new variable** in your component or layout SCSS.
4. **Rebuild the Hugo site** and check changes at `localhost:1313`.
5. **Test for accessibility and consistency** (e.g., color contrast, responsive scaling).
6. **Document any major changes** in commit messages and PRs.

## Best Practices & Workflow

- **Always use variables**—never hardcode colors, font sizes, or spacing in component styles.
- **Use rem units** for all spacing and typography for accessibility.
- **Test visually** after changes: run Hugo locally and check in multiple browsers/devices.
- **Check color contrast** for accessibility (use tools like WebAIM Contrast Checker).
- **Keep tokens DRY**: update in one place, use everywhere.
- **Sync with Figma**: If design tokens change in Figma, update the corresponding variables and document the change.

## Example: Adding a New Color

1. Add to `colors.scss`:
   ```scss
   --color-success-bg: #d4edda;
   ```
2. Use in a component:
   ```scss
   .alert-success {
     background: var(--color-success-bg);
   }
   ```
3. Rebuild and test.

## Questions or Issues?

If you have questions or need to update the theme, check this document first. For major changes, coordinate with the team and document your process.
