# PBI-004: Global Styles & Theme

## Overview

Establish a centralized theme for the Doula Cooperative website, including color palette, typography, and spacing, to ensure visual consistency and ease of maintenance.

## Problem Statement

The site needs a unified set of design tokens and global styles to maintain a consistent look and feel across all pages and components.

## User Stories

- As a developer, I want a centralized theme for colors, typography, and spacing so the site looks consistent and is easy to maintain.

## Technical Approach

- Define color palette, typography, and spacing based on Figma ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=24-60))
- Implement as CSS variables, design tokens, or theme provider
- Ensure styles are reusable and easy to update

## UX/UI Considerations

- Match Figma for all global styles
- Ensure accessibility (contrast, font sizes)

## Acceptance Criteria

- Color palette, fonts, and spacing match Figma
- Styles are reusable
- Easy to update globally

## Dependencies

- Access to finalized Figma design tokens

## Open Questions

- Should dark mode or other themes be supported?
- Who approves the final style guide?
