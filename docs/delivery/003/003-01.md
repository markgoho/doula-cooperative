2.  Node IDs for icons:

    - X: `I70:138;70:271`

3.  Save the files as `facebook.svg`, `x.svg`, and `instagram.svg`.
4.  Create the directory `hugo/static/assets/icons/` if it doesn't exist.
5.  Place the downloaded SVG files into the directory.
