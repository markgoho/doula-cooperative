## Requirements

- Create a new file: `hugo/assets/scss/footer.scss`.
- Import the new file into `hugo/assets/scss/styles.scss`.
- Use existing SCSS variables/tokens for colors, fonts, and spacing where possible.
- The styling should match the Figma design precisely.

## Implementation Plan

1.  In `footer.scss`, target the main `.footer` class for overall desktop styles (background color, top border, padding).
2.  Use **CSS Grid** on the `.footer__main` element to create the multi-column desktop layout for the brand information and navigation links, as specified in the Figma design.
3.  Use the `style` and `text-style` information from the Figma analysis to apply correct typography (font sizes, weights) and colors for the desktop view, using existing SCSS variables/tokens.
4.  Style the individual footer columns (`.footer__col`), link lists (`.footer__links`), and the social media icon section (`.footer__social`) for the desktop layout.
5.  Style the `.footer__bottom` section, ensuring the copyright and login link are correctly aligned.

## Test Plan

- Run the Hugo server and observe the footer styling.
- Compare the result with the Figma design to ensure a match.
- Check that existing style tokens have been used correctly.
