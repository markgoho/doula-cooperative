## Requirements

- Create a new file: `hugo/assets/scss/footer.scss`.
- Import the new file into `hugo/assets/scss/styles.scss`.
- Use existing SCSS variables/tokens for colors, fonts, and spacing where possible.
- The styling should match the Figma design precisely.

## Implementation Plan

1.  Create the `footer.scss` file.
2.  Add an `@use 'footer';` rule to `styles.scss`.
3.  In `footer.scss`, target the main footer container class.
4.  Style the background color and top border.
5.  Implement the multi-column layout using CSS Grid or Flexbox.
6.  Style the typography for headings, links, and paragraphs according to the design.
7.  Style the social media icon section.
8.  Use color tokens from `colors.scss`.

## Test Plan

- Run the Hugo server and observe the footer styling.
- Compare the result with the Figma design to ensure a match.
- Check that existing style tokens have been used correctly.
