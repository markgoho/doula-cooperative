# PBI-003: Global Footer

## Overview

Implement a reusable, site-wide footer for the Doula Cooperative website, matching the Figma design and providing consistent information and links across all pages.

## Problem Statement

The site needs a consistent, accessible, and responsive footer to provide important information and links to users.

## User Stories

- As a visitor, I want a consistent footer with contact info and links so I can find important information easily.

## Technical Approach

- Build a footer component matching the Figma design ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=70-138&t=uppXxhetn2HaHqiQ-4))
- Include contact info, social links, and secondary navigation as per design
- Ensure responsiveness and accessibility

## UX/UI Considerations

- Follow Figma for layout, colors, and typography
- Footer content should be clear and easy to find

## Acceptance Criteria

- Footer matches Figma design
- Contact/social links work
- Responsive and accessible
- Present on all pages

## Dependencies

- Access to Figma assets (icons, text)
- Finalized footer content

## Open Questions

- Are there any dynamic elements in the footer?
- Who provides the final contact info and links?
