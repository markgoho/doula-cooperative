- The footer must be visually identical to the Figma design.
- All links in the footer must be present (even if pointing to '#').
- The footer must be fully responsive.

## Implementation Plan

2.  Take a screenshot of the implemented footer.
3.  Compare the screenshot side-by-side with the Figma design.

6.  Use accessibility checking tools (like browser extensions) to evaluate contrast and other factors.
