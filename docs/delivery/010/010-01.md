## Description

Implement the client-side integration of Google reCAPTCHA v3 on both the Find a Doula and general contact forms. This will ensure only humans can submit these forms, reducing spam and abuse. ## Requirements

- Integrate reCAPTCHA v3 on the client side for both forms.
- Use the official reCAPTCHA v3 API and your site key.
- On form submission, obtain a reCAPTCHA token using `grecaptcha.execute` with an appropriate action name.
- Send the token to the backend (Firebase Cloud Function) along with the form data.
- Disable the submit button until reCAPTCHA verification passes.
- Provide user feedback if submission is blocked due to reCAPTCHA.
- Ensure accessibility and responsiveness are maintained.
- Reference the official docs: https://developers.google.com/recaptcha/docs/v3

## Implementation Plan

1. Add the reCAPTCHA v3 script to the site’s head (using your site key).
2. Update both contact forms to:
   - Trigger `grecaptcha.execute` on page load or form interaction.
   - Store the token and enable the submit button only if verification passes.
   - On submit, send the form data and token to the backend endpoint.
3. Adapt the following example snippet to your project’s structure:

```html
{{ define "head-scripts" }}
<script src="https://www.google.com/recaptcha/api.js?render=YOUR_SITE_KEY"></script>
{{ end }} {{ define "main" }}
<!-- ...form HTML as in your project... -->
{{ end }} {{- define "body-scripts" -}}
<script>
  var token;
  let safeToSubmit = false;
  var submitBtn = document.querySelector(".submit");

  async function submitForm() {
    // Collect form data and send to backend with token
  }

  async function checkRecaptcha(recaptchaToken) {
    // Call your backend to verify the token
  }

  grecaptcha.ready(async () => {
    token = await grecaptcha.execute("YOUR_SITE_KEY", { action: "contact" });
    verification = await checkRecaptcha(token);
    if (
      (verification.success && verification.score > 0.5) ||
      verification.hostname === "localhost"
    ) {
      safeToSubmit = true;
      submitBtn.removeAttribute("disabled");
    }
  });

  submitBtn.addEventListener("click", submitForm, false);
</script>
{{- end -}}
```

- Replace `YOUR_SITE_KEY` with your actual reCAPTCHA v3 site key.
- Update the backend endpoint URLs as needed.
- Ensure the logic fits your form structure and UX.
