## Requirements

- Create a Firebase Cloud Function to verify reCAPTCHA v3 tokens using the Google siteverify API.
- Accept the token and form data from the client, and only process the submission if the verification is successful and the score is above 0.5.
- Store valid submissions in Firestore (or as appropriate for your project).
- Optionally, send notification emails (e.g., via Mailgun) for new messages.
- Ensure CORS is handled correctly for both verification and form submission endpoints.
- Reference the official docs: https://developers.google.com/recaptcha/docs/v3

## Implementation Plan

1. Implement a function (e.g., `verifyRecaptcha`) to accept a token from the client, call the Google siteverify API, and return the verification result.
2. Implement a function (e.g., `postForm`) to accept form submissions, verify the reCAPTCHA token, and store/process the message if valid.
3. Optionally, implement a Firestore trigger (e.g., `sendContactMessage`) to send notification emails for new messages.
4. Adapt the following example snippet to your project’s structure:

```ts
export const verifyRecaptcha = functions.https.onRequest(
  async (req: any, res: any) => {
    res.set("Access-Control-Allow-Origin", "*");
    res.set("Access-Control-Allow-Methods", "GET");

    const secret = "YOUR_SECRET_KEY";
    const response = req.query.token;

    const options = {
      method: "POST",
      uri: `https://www.google.com/recaptcha/api/siteverify?secret=${secret}&response=${response}`,
      resolveWithFullResponse: true,
      json: true,
    };

    const { body: verification } = await rp(options);

    res.status(200).send(verification);
  },
);
```

- Update logic to check the verification score and only process valid submissions.
- Ensure endpoints are secure and handle errors gracefully.
- Adapt Firestore/Mailgun logic as needed for your project.
