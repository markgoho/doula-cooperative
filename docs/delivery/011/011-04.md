# 011-04 Link taxonomy list to canonical profile pages

## Description

Ensure that all doula list (taxonomy) pages link to the correct canonical profile page for each doula, and that no duplicate or alternate profile URLs exist.

## Requirements

- All doula cards on taxonomy list pages must link to the canonical profile page (e.g., /doulas/jane-doe).
- No alternate or duplicate profile URLs should be generated or linked.
- Internal links should use Hugo’s `.Permalink` or `.RelPermalink` for accuracy.

## Implementation Plan

1. Update taxonomy list templates to ensure doula cards link to `.Permalink` of each doula’s profile.
2. Audit site for any alternate or duplicate profile URLs and remove/fix as needed.
3. Add tests or manual checks to verify only canonical URLs are used.

## Verification

- All doula list pages link only to canonical profile pages.
- No duplicate or alternate profile URLs exist in the site output.
