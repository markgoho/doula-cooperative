# 011-02 Create taxonomy list page template

## Description

Implement a Hugo template for taxonomy-driven doula list pages (e.g., /doulas/birth, /doulas/postpartum) that matches the Figma design and lists all doulas of the selected type.

## Requirements

- Hugo must render a list page for each doula type taxonomy (e.g., /doulas/birth).
- The list page must match the layout and content of the Figma frame ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=154-673)).
- Each doula is displayed as a card with summary info and a link to their canonical profile page.
- The page is responsive and accessible.

## Implementation Plan

1. Create a Hugo template for taxonomy list pages (e.g., `layouts/types/list.html` or `layouts/_default/terms.html`).
2. Use a loop to display all doulas in the selected taxonomy.
3. Style the page to match the Figma design, including headings, cards, and layout.
4. Ensure each card links to the canonical profile page using `.Permalink`.
5. Test responsiveness and accessibility.

## Verification

- Visiting /doulas/birth or /doulas/postpartum shows a styled list of doulas of that type.
- Each doula card links to the correct canonical profile page.
- The page matches the Figma design and is responsive.
