# 011-03 Create canonical doula profile page template

## Description

Implement a Hugo template for canonical doula profile pages (e.g., /doulas/jane-doe) with SEO optimization and accessibility, matching the Figma design.

## Requirements

- Hugo must render a canonical profile page for each doula at /doulas/{slug}.
- The profile page must match the layout and content of the Figma frame ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=154-673)).
- The page must include SEO meta tags, canonical URL, and structured data.
- The page is accessible and responsive.

## Implementation Plan

1. Create a Hugo template for doula profile pages (e.g., `layouts/doulas/single.html`).
2. Render all relevant doula data from front matter.
3. Add SEO meta tags and canonical URL using front matter fields.
4. Add structured data (JSON-LD) for Person/LocalBusiness.
5. Style the page to match the Figma design.
6. Test accessibility and responsiveness.

## Verification

- Visiting /doulas/{slug} shows the correct doula profile with all info.
- The page includes correct SEO meta tags and canonical URL.
- The page matches the Figma design and is accessible.
