# 011-01 Define Hugo taxonomy and content structure

## Description

Specify the Hugo configuration and content structure needed to support taxonomy-driven doula list pages and canonical doula profile pages. Provide a sample config, folder structure, and example content files.

## Requirements

- Hugo must generate taxonomy list pages (e.g., /doulas/birth, /doulas/postpartum) from a taxonomy (e.g., `type`).
- Each doula must have a single, canonical profile page at /doulas/{slug}.
- The config and structure must support SEO best practices and easy linking.

## Implementation Plan

1. Define Hugo taxonomy in `config.toml` (or `hugo.toml`).
2. Specify folder/content structure for doulas and taxonomy.
3. Provide example content files for doulas with front matter.
4. Add notes on slug generation and uniqueness.

## Verification

- Hugo builds taxonomy list pages and canonical doula profile pages as described.
- URLs match the pattern /doulas/{taxonomy} and /doulas/{slug}.
- Example content renders correctly in local build.

## Files Modified

- hugo/hugo.toml (or config.toml)
- hugo/content/doulas/

## Sample Hugo Config and Structure

### 1. Taxonomy Definition (hugo.toml)

```toml
[taxonomies]
  type = "types"
```

### 2. Content Structure

```
hugo/
  content/
    doulas/
      jane-doe.md
      amina-fernandez.md
      ...
```

### 3. Example Doula Content File (content/doulas/jane-doe.md)

```markdown
---
title: "Jane Doe"
date: 2024-07-10
type: ["birth", "postpartum"]
slug: "jane-doe"
description: "Experienced birth and postpartum doula in Boston."
seo_title: "Jane Doe – Birth & Postpartum Doula | Doula Cooperative"
seo_description: "Learn about Jane Doe, a certified birth and postpartum doula serving Boston families."
---

Jane Doe is a certified doula with 10+ years of experience supporting families through birth and postpartum journeys...
```

### 4. Taxonomy List Pages

- `/doulas/birth/` – lists all doulas with `type = "birth"`
- `/doulas/postpartum/` – lists all doulas with `type = "postpartum"`

### 5. Canonical Profile Pages

- `/doulas/jane-doe/` – canonical profile for Jane Doe

### 6. Notes on Slug Uniqueness

- Ensure each doula’s `slug` is unique. If two doulas have the same name, append a differentiator (e.g., `jane-doe-boston`).
- Use the `slug` field in front matter to control the URL.
