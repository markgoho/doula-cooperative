# PBI-009: Find a Doula Page

## Overview

This PBI covers the implementation of the "Find a Doula" page, enabling visitors to search for, browse, and connect with doulas based on their needs. The page will closely follow the Figma design and provide a seamless, accessible experience for users seeking doula support.

## Problem Statement

Visitors need an easy way to find and connect with doulas who match their specific needs, preferences, and location. The current site does not provide a dedicated, user-friendly interface for this purpose.

## User Stories

- As a visitor, I want to find and connect with the right doula for my needs, so I can get personalized support throughout my journey.

## Technical Approach

- Implement the page layout and components as shown in the Figma design ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=152-672)).
- Add search functionality for doula profiles (by name, specialization, location, keywords).
- Implement browse-by-type buttons (Fertility, Birth, Lactation, Postpartum, Childbirth Educators).
- Build the contact form with all fields from Figma, including validation and submission handling.
- Display a clear explanation of the process after form submission.
- Ensure full responsiveness and accessibility.

## UX/UI Considerations

- Match all text, buttons, and sections to the Figma design.
- Use accessible form controls and semantic HTML.
- Ensure the page is visually appealing and easy to navigate on all devices.
- Provide clear feedback on form submission and errors.

## Acceptance Criteria

- The Find a Doula page matches the layout and content of the Figma frame ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=152-672)).
- Users can search doulas by name, specialization, location, and keywords.
- Users can browse doulas by type (Fertility, Birth, Lactation, Postpartum, Childbirth Educators).
- Contact form collects all fields shown in Figma and submits successfully.
- After submission, users see a clear explanation of what happens next.
- Page is responsive and accessible.
- All text, buttons, and sections from Figma are present.

## Dependencies

- Figma design for "Find a Doula" page ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=152-672))
- Reusable UI components (buttons, form fields, etc.)

## Open Questions

- Should doula profiles be filterable by additional criteria (e.g., availability, languages spoken)?
- What backend/API support is required for search and form submission?
