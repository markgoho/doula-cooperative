# PBI-013: About the Doula Cooperative Page

## Overview

This PBI covers the implementation of the About the Doula Cooperative page, providing information about the cooperative's mission, membership, and board, as designed in the Figma frame ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=155-675)).

## Problem Statement

Visitors need a clear, engaging, and informative page to learn about the Doula Cooperative, its mission, values, and the people who lead it.

## User Stories

- As a visitor, I want to learn about the Doula Cooperative, its mission, members, and board, so I can understand its purpose and the people behind it.

## Technical Approach

- Implement a new page matching the Figma frame structure and content.
- Use reusable components for board member cards.
- Ensure all text, images, and sections from Figma are present.
- Ensure responsiveness and accessibility.

## UX/UI Considerations

- Match Figma layout, typography, and visual hierarchy.
- Board member cards must display names, roles, and headshots as shown.
- Content should be easy to read and well-organized.

## Acceptance Criteria

- The About the Doula Cooperative page matches the layout and content of the Figma frame ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=155-675)).
- Sections for "About the Doula Cooperative", "Our Mission", "Who We Are", and "Our Board" are present and match Figma.
- Board member cards display names, roles, and headshots as shown in Figma.
- All text, images, and sections from Figma are present.
- Page is responsive and accessible.
- All content is easy to read and well-organized.

## Dependencies

- Figma design for About page.

## Open Questions

- Are there any additional board members or content updates not reflected in the current Figma frame?
- Should board member profiles link to individual pages?
