## Requirements

- Create a new partial for the board member card.
- The partial should accept parameters for the member's name, role, and image.
- The HTML structure should match the component in the Figma design.

## Implementation Plan

1.  Create a new partial file at `hugo/layouts/partials/about-cooperative/board-member-card.html`.
2.  The partial will take a map as a parameter, with keys for `name`, `role`, and `image`.
3.  Implement the HTML structure for the card, using the provided parameters to populate the data.
4.  The image will be handled in a later task. For now, a placeholder can be used.

## Verification

- The partial can be called from a layout file.
- When called with data, it renders the name and role correctly.
