# PBI-005: Responsive Layout System

## Overview

Implement a shared responsive layout system for the Doula Cooperative website, ensuring all pages adapt to different screen sizes and devices.

## Problem Statement

The site needs a consistent, reusable layout system to ensure a great experience on mobile, tablet, and desktop devices.

## User Stories

- As a visitor, I want the site to look good on any device so I can browse comfortably.

## Technical Approach

- Define breakpoints and grid system based on Figma ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=24-60))
- Implement shared layout containers and utilities
- Test responsiveness on all major devices

## UX/UI Considerations

- Match Figma responsiveness
- Ensure layouts are flexible and accessible

## Acceptance Criteria

- Layout adapts to mobile, tablet, desktop
- Uses shared grid/breakpoints
- Matches Figma responsiveness

## Dependencies

- Access to Figma layout specs

- Are there any device-specific features to consider?
- Who signs off on responsive breakpoints?
