# PBI-002: Global Header (Navigation Bar)

## Overview

Implement a reusable, site-wide header (navigation bar) for the Doula Cooperative website, matching the Figma design and providing consistent navigation across all pages.

## Problem Statement

The site needs a consistent, accessible, and responsive header to allow users to navigate easily and reinforce branding.

## User Stories

- As a visitor, I want a consistent header with navigation links on every page so I can easily explore the site.

## Technical Approach

- Build a header component matching the Figma design ([View Figma](https://www.figma.com/design/N1hDApgRTKrIRyu3RdFrFM/Doula-Cooperative?node-id=52-226&t=uppXxhetn2HaHqiQ-4))
- Include site logo/branding and navigation links
- Ensure responsiveness and accessibility
- Integrate with site routing

## UX/UI Considerations

- Follow Figma for layout, colors, and typography
- Navigation links should be clear and easy to use
- Header should be sticky or fixed as per design

## Acceptance Criteria

- Header matches Figma design
- Navigation links work on all pages
- Responsive and accessible
- Branding/logo present

## Dependencies

- Access to Figma assets (logo, icons, text)
- Finalized navigation structure

## Open Questions

- Are there any dynamic elements (e.g., user login state) in the header?
- Should the header be sticky or static?
