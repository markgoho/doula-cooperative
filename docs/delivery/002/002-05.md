## Implementation Details

- **Location:** The header's HTML structure is in the Hugo partial at `hugo/layouts/partials/header.html`.
- **Styling:**
  - All header styles are in `hugo/assets/scss/header.scss`.
  - This partial is imported into the main stylesheet at `hugo/assets/scss/styles.scss`.
- **Design Tokens:**
  - The header uses design tokens from `colors.scss`, `typography.scss`, and `spacing.scss`.
  - **New tokens added:** `--spacing-header-height`, `--spacing-nav-gap`, `--spacing-btn-padding-x`, `--spacing-btn-radius`.
- **Responsiveness:**
  - The header uses container queries for responsive layout.
  - The breakpoint is `43.75rem` (`700px`).
- **Customization:**
  - To change navigation links, edit the `<ul>` in `header.html`.
  - To change styles, update the SCSS variables or the `.navbar` classes in `header.scss`.
